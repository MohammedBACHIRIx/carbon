# Carbon

## Core Identity
A tool for creating and sharing beautiful images of source code. 

## Target Audience
Developers, DevRels, and content creators looking to share snippets on social media.

## UI Register: The Aesthetic Creator
- **Purpose**: A highly polished, beautiful interface that inspires creativity.
- **Vibe**: Dark mode, glassmorphism, subtle gradients, highly refined.
- **Rule**: The UI should feel as premium as the images it generates. Use rounded corners, soft glow effects, and modern typography.
