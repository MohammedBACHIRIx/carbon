# Carbon Design System

## Typography
- **Primary Font**: `Inter`, system sans-serif.
- **Scale**:
  - Clean and legible, relying on font-weight for hierarchy rather than large size differences.

## Colors
- **Backgrounds**:
  - Global Background: `#121212`
  - Floating Panels: `#1e1e1e` (or glass effect `rgba(30, 30, 30, 0.6)`)
- **Text**:
  - Primary: `#ffffff`
  - Muted: `#888888`
- **Accents**:
  - Brand/Primary: `#3B82F6` (Vibrant Blue)

## Spacing & Layout
- **Radius**:
  - Floating Panels: `12px` (Modern, soft)
  - Buttons: `8px`
  - Code Window: `8px`

## The Aesthetic Creator Rules
- Use glassmorphism (backdrop-filter: blur) where appropriate.
- Hover states should add a subtle glow or brightness shift, rather than flat background changes.
- Ensure transitions on color, background, and transform are universally 0.2s ease.
